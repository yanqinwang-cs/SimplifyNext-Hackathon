# Validation evidence

This directory documents the submission boundary for retained validation artifacts.

Retained evidence includes:

- successful deterministic model-screen results under `experiments/model_screen/results/`;
- the Case 1 GLM trace under `experiments/investigation_smoke/results/`, retained because it records a structured-output contract failure rather than an infrastructure failure;
- controlled fixtures under `tests/fixtures/` and deterministic backend/frontend tests;
- methodology and acceptance summaries under `docs/`.

Stale credential, authentication, provider-setup, and sandbox-network failure artifacts are intentionally excluded. No raw credentials, API keys, authorization headers, or credential metadata are included in the retained artifacts.
